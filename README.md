# **Ivy – A Fun & Professional Chatbot**

Ivy is a chatbot built with **Flask**, **HTML/CSS/JS**, and a pinch of sarcasm.  
She can chat casually, crack jokes, answer general questions, do math, tell time/date,  
and always reply with a witty twist.  

---

## **Features**
- **Small talk** – greetings, goodbyes, moods, jokes, random facts  
- **Math support** – ask Ivy to calculate expressions like `12*9`  
- **Date & time** – Ivy knows what day and time it is  
- **Personality layer** – every response gets wrapped in humor for a unique feel  
- **Custom UI** – clean, modern design with a dark professional gradient theme   

---

## **Tech Stack**
- **Backend:** Python (Flask)  
- **Frontend:** HTML, CSS, JavaScript  
- **Data:** `intents.json` for small talk responses  
- **NLP-ish Logic:** Keyword matching + dynamic wrappers for humor
